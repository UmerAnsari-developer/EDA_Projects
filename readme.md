# EDA Projects

Portfolio of Exploratory Data Analysis projects — each with a full Jupyter notebook, source dataset, and project readme.

## Projects

| Project | Dataset | Focus |
|---------|---------|-------|
| [Customer Churn Analysis](Customer_Churn_Analysis/) | Telco churn (7,043 customers) | Churn drivers, at-risk segments, retention actions |
| [Netflix Shows Analysis](Netflix_Shows_Analysis/) | Netflix catalogue (8,807 titles) | Catalogue composition, genres, geography, content age |
| [Walmart Sales EDA](Walmart_EDA/) | Walmart transactions (5,000 txns) | Store performance, promotion effectiveness, forecast accuracy |

## Tech Stack

- Python — pandas, numpy, matplotlib, seaborn, scipy
- Jupyter Notebook

## Usage

Open any project folder and launch its notebook:

```bash
jupyter notebook <Project_Folder>/<notebook>.ipynb
```
